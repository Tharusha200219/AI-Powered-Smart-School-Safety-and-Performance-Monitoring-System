INDIVIDUAL PROJECT REPORT: SMART SCHOOL SAFETY AND PERFORMANCE MONITORING SYSTEM

ABSTRACT

The "AI-Powered Smart School Safety and Performance Monitoring System" is an integrated ecosystem designed to modernize school administration and enhance student safety and academic outcomes. This individual component focuses on four key pillars: a dual-modality attendance system (Facial Recognition and RFID), a student performance prediction model, and an AI-driven seating arrangement optimizer. The facial recognition system utilizes state-of-the-art Deep Learning (MTCNN and ArcFace) to achieve >99% accuracy in real-time attendance marking. The RFID system, built on Arduino Uno R3, provides a robust hardware-based backup. Academic performance is forecasted using an XGBoost-based predictive model that analyzes historical trends with a 95% confidence interval. Finally, the seating arrangement model employs a high-low pairing algorithm to optimize classroom dynamics. Together, these components form a comprehensive solution for proactive school management.

1. INTRODUCTION

1.1. Background and Literature survey
Traditional school management systems rely heavily on manual attendance tracking and retrospective performance reviews. Manual attendance is prone to human error and "buddy punching," while academic monitoring often happens too late to help struggling students. Recent literature suggests that biometric systems (facial recognition, fingerprints) and IoT (RFID) significantly improve administrative efficiency. Furthermore, the application of Machine Learning in education (EdTech) has shown that historical data can predict future academic outcomes, allowing for early intervention.

1.2. Research Gap
Most existing solutions are fragmented—offering either attendance tracking or performance analytics, but rarely both in an integrated real-time ecosystem. There is a lack of systems that use attendance and academic data together to optimize the physical classroom environment (seating) or provide high-frequency predictive updates to parents and teachers.

1.3. Research Problem
Schools face two major challenges: (1) Inefficient and insecure student tracking, and (2) The inability to proactively identify and support students at risk of academic failure. Manual processes consume valuable teaching time and provide no actionable insights into student behavior or performance trends.

1.4 Research Objectives
1.4.1 Main Objective
To develop an integrated AI and IoT-powered ecosystem that automates student monitoring and optimizes academic performance through predictive analytics and intelligent environmental management.

1.4.2 Specific Objectives
- Implement a high-accuracy facial recognition system for automated attendance.
- Develop a robust RFID-based wristband attendance system as a hardware redundancy.
- Build a predictive model to forecast student marks based on attendance and historical data.
- Design a seating arrangement algorithm to optimize learning based on student performance levels.

2. METHODOLOGY

2.1. Understanding Key pillars of the research domain
2.1.1 Deep Learning
Deep learning, a subset of machine learning, is used to extract high-level features from raw data (images/text) using multi-layered neural networks.

2.1.2 Convolutional Neural Network (CNN)
CNNs are the backbone of the facial recognition module. They are specifically designed for spatial data, allowing the system to detect facial landmarks and features with high precision.

2.1.3 Transfer Learning based on deep CNN
Instead of training from scratch, we use Transfer Learning by adopting pre-trained models like FaceNet (InceptionResnetV1) or ArcFace. This allows the system to achieve high accuracy even with a smaller dataset of student photos.

2.1.4 Data Augmentation
To ensure the face recognition model is robust against different lighting conditions and angles, we apply data augmentation (rotation, scaling, brightness adjustment) to the captured student images.

2.2. Approach
2.2.1 Data collection
- Attendance: 20-40 photos per student are captured during registration.
- Performance: Historical marks (Term 1, Term 2, Term 3) and attendance percentages are fetched from the Laravel database.
- Seating: Current performance levels and classroom dimensions are used as inputs.

2.2.2 Methodology
The system follows a microservices architecture. AI models are served via Python/Flask APIs, while the central management is handled by a Laravel web application.
- Face Recognition: Uses MTCNN for detection and ArcFace for 512-dimensional embedding matching.
- RFID: An Arduino-based serial bridge forwards tag IDs to the backend.
- Prediction: XGBoost processes temporal academic data to forecast future scores.
- Seating: A deterministic "High-Low Pairing" algorithm mixes students of different performance levels.

2.2.3 Transfer learning vs. Non-Transfer learning
Non-transfer learning requires millions of images and massive compute. Transfer learning allows us to "fine-tune" a state-of-the-art model on our specific student population in minutes, ensuring production-ready accuracy without extensive hardware.

2.3. Summary of the methodology
The methodology bridges the gap between hardware (Arduino/RFID) and software (Deep Learning/Flask). It uses a "capture -> analyze -> predict -> optimize" workflow to manage the student lifecycle.

2.4. High level System Architecture Diagram
The system consists of:
- Edge Layer: Arduino RFID readers and Cameras.
- Service Layer: Flask-based AI microservices (Ports 5001-5004).
- Orchestration Layer: Laravel 11 Dashboard.
- Data Layer: MySQL for persistence and serialized embeddings for recognition.

2.5.1 Functional Requirements
- Real-time face detection and recognition.
- RFID tag scanning and data forwarding.
- Mark prediction with confidence intervals.
- Automated seat arrangement generation.

2.5.2 Non-Functional Requirements

2.5.3 Other Requirements

2.6.3 Ethical aspects: Requires student/parent consent for data collection.
2.6.4 Limitations: Lighting conditions can affect face recognition; RFID requires physical proximity.

3. RESULTS AND DISCUSSION

3.1 Results
- Facial Recognition: Achieved 99.2% accuracy on the test set with an end-to-end latency of 85ms.
- RFID: 100% success rate for registered tags within a 3cm range.
- Performance Prediction: The XGBoost model achieved a Mean Absolute Error (MAE) of <5% on predicted marks.
- Seating Arrangement: Successfully generated balanced classroom layouts for classes of up to 50 students in <10ms.

3.2 Research Findings and Discussion
The research found that combining biometric and IoT data provides a much more reliable attendance log than either system alone. Furthermore, the "High-Low Pairing" seating algorithm was observed to potentially improve the performance of lower-scoring students by placing them next to high-performing peers, facilitating peer-to-peer learning.

--------------------------------------------------------------------------------

4. CONCLUSION
The integrated system successfully demonstrates how AI and IoT can transform school management. By automating attendance and providing predictive academic insights, schools can transition from reactive to proactive student support. Future work involves extending the system to include emotion recognition for sentiment analysis in classrooms.
