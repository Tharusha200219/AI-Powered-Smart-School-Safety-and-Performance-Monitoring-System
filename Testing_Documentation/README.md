# 📊 Smart School System - Testing Documentation

This folder contains the comprehensive testing documentation, including evaluation scripts and performance charts for the core AI modules of the Smart School Safety and Performance Monitoring System.

## 📁 Directory Structure

### 1. [Facial Recognition Attendance Systems](./Facial%20Recognition%20Attendance%20Systems/)
- **`testing_code.py`**: Evaluation script for face embedding stability and recognition confidence.
- **`accuracy_dashboard.png`**: Regression plot showing the relationship between stability and confidence.
- **`summary.png`**: Key Performance Indicators (KPI) for the facial recognition model.

### 2. [student-performance-prediction-model](./student-performance-prediction-model/)
- **`testing_code.py`**: Script to evaluate the RandomForestRegressor performance.
- **`actual_vs_predicted.png`**: Scatter plot showing the model's prediction accuracy against real data.
- **`error_distribution.png`**: Histogram of prediction errors.
- **`accuracy_metrics.png`**: Summary of R², MAE, and RMSE metrics.

### 3. [student-seating-arrangement-model](./student-seating-arrangement-model/)
- **`testing_code.py`**: Optimization algorithm evaluation script.
- **`seating_layout.png`**: Heatmap visualization of student performance distribution in the classroom.
- **`evaluation_metrics.png`**: Bar chart showing Balance and Pairing scores.
- **`summary.png`**: Overall algorithm effectiveness summary.

### 4. [RFID Part](./RFID%20Part/)
- **`testing_code.py`**: RFID hardware performance simulation and test script.
- **`read_success_rate.png`**: Performance curve showing success rate over different distances.
- **`tag_latency.png`**: Bar chart comparing detection times for various RFID tags.
- **`summary.png`**: Hardware reliability and response time summary.

---
*All charts were generated with white backgrounds for professional documentation compatibility.*
